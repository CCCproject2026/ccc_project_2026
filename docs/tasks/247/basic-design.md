# Basic Design — 基本設計

## Task情報

Issue #247。領域: common。

## 目的・背景

正本スキルと `.agents`、`.claude`、`.github`、`.opencode` の生成コピーに差分があり、ツールごとに異なる作業手順を参照する状態を解消する。

## 対象範囲・対象外

対象は `fastapi-ml-iot`、`iot-data-contract`、`nextjs-frontend` の4ツール向けコピーと、OpenCodeの `project-explainer` 本文・参照資料。正本・未管理のローカル設定・アプリケーションコードは変更しない。

## システム構成・コンポーネント責務

`docs/agent-coding/skills/` が正本、`scripts/agent-coding/sync.py` がコピー生成の唯一の実装である。生成先はマーカーのある管理済みファイルだけを受け取る。

## データフロー・処理フロー

正本読込 → `sync.py --write` が生成先を検査して差分だけ書込み → `sync.py --check` で全管理ファイルの一致を確認する。

## 外部システムとの連携

外部サービス・DB・実機への接続はない。

## 非機能要件

未管理ファイルまたはシンボリックリンクへの上書きを拒否し、ローカル設定を保護する。

## 制約・前提条件

生成コピーは直接編集せず、正本を更新して同期する。今回の正本は既に意図した内容を持つため、コピーのみ更新する。

## 未決事項・備考

生成対象外の古い管理済みファイルを検出した場合は、スクリプトが停止するため個別に確認する。
