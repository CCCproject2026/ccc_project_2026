# MCP integrations

Only Context7 is registered, disabled by default. It provides version-aware library documentation through the remote `https://mcp.context7.com/mcp` endpoint. The service supports OAuth 2.0 and API key auth depending on client setup; no key is embedded. The V1 CLI connection check failed with DNS `ENOTFOUND mcp.context7.com` in this environment, so no tools could be listed. This is a network-resolution failure, not evidence that the endpoint or credentials are invalid. Leave disabled until DNS/network is available; then run `opencode mcp list` and inspect the discovered tools before use. The supplied configuration uses installed CLI V1 shape (`mcp.context7`, `enabled: false`).

GitHub: official MCP server exists; requires GitHub authentication and can expose read/write operations. Not configured because no repository task scope or token scope was authorized.

Filesystem: official/reference servers exist, but OpenCode already has native filesystem tools; avoid expanding duplicate access. PostgreSQL: community/official ecosystem servers exist, but DB credentials and access mode were not authorized. AWS: multiple vendor/community MCP options exist; no AWS identity or production risk was reviewed, so none configured. Browser: Playwright MCP is available; launches browser automation and may interact with websites, so not configured. Memory: diverse third-party servers and plugins; persistent user data needs an explicit retention/privacy policy, so not configured. Sequential Thinking: optional reasoning server, but no measurable need over native planning and it adds tool context; omitted. Internal tools: not present in the accessible workspace and cannot be configured safely without endpoint/schema/auth details.

## Candidate inventory

| Integration | Official / representative implementation and auth | Tools and risk | Decision |
|---|---|---|---|
| GitHub | GitHub maintains [github-mcp-server](https://github.com/github/github-mcp-server). Local stdio deployments commonly use `GITHUB_PERSONAL_ACCESS_TOKEN`; remote service auth depends on endpoint. | Repository, issue, PR, search and other toolsets vary by version. Server supports toolsets, individual tool allowlists, read-only and lockdown modes, but read-only mode does not reduce the token's underlying GitHub API authority. | Defer. If needed, use least-scope token, explicitly allow read toolsets, enable server read-only, then inspect tools. |
| Context7 | Official hosted endpoint, OAuth 2.0 or API key; local npm package is also offered. | Library resolution and documentation query tools; sends library/question context to a third party. | Registered but disabled. The live DNS check failed (`ENOTFOUND`), so tools/auth were not verified. |
| Filesystem | MCP reference server `@modelcontextprotocol/server-filesystem`; no auth, local stdio. Command arguments define allowed roots. | Read/write/list/search on exposed directories; path boundary and symlink behavior must be reviewed. | Omitted because native OpenCode file tools already exist. Avoid redundant broad disk access. |
| PostgreSQL | Official MCP reference server has been archived; community implementations include `crystaldba/postgres-mcp`. Typical auth is a database URL or environment variables. | SQL/schema/inspection tools may permit arbitrary queries or writes, depending on implementation and role. | Omitted. No DB endpoint or read-only role is authorized. Use a dedicated least-privilege role and read-only transaction mode if later approved. |
| AWS | AWS Labs [MCP collection](https://github.com/awslabs/mcp) includes AWS documentation and service-specific servers; auth generally uses AWS SDK credential chain/profile and IAM. | Documentation-only tools differ from API/action servers. Service tools can create, modify, or delete resources and incur cost. | Omitted. A documentation-only server could be considered later; never attach broad production IAM by default. |
| Browser | Microsoft Playwright MCP (`@playwright/mcp`) is a commonly used local stdio server; browser profile/session can carry site auth. | Navigation, snapshots, clicks, forms, and browser evaluation; can expose authenticated pages or submit external writes. | Omitted; no browser workflow needs it in this package. |
| Memory | MCP reference server `@modelcontextprotocol/server-memory` stores a local knowledge graph; no external auth by default. | Create/search/update/delete persistent entities. Persistence can retain sensitive or incorrect information. | Omitted pending retention, scope, and deletion policy. |
| Sequential Thinking | MCP reference server `@modelcontextprotocol/server-sequential-thinking`; local stdio, no external auth. | Structured thought-sequence tool; adds prompt surface and context but no external capability. | Omitted because native planner plus commands are sufficient. |
| Internal APIs | No endpoint, schema, or credential configuration exists in the inspected workspace. | Unknown until reviewed; could expose privileged internal operations. | Not configured. Obtain owner-approved tool schemas, auth, read/write classification, audit and timeout requirements first. |

For any candidate, evaluate maintainer/source, license, auth, environment variable names, exposed tools, read/write capabilities, logging, network/data boundary, and OpenCode permission rules. Test connectivity and inspect actual tools before relying on it. The official MCP reference list identifies Filesystem and Memory as examples, not managed production services; verify each server's present maintenance and license before use. No DB/AWS/GitHub/browser auth test was attempted.
